### Which error shape `b04d327` (#53) used

**The legacy `core/exceptions.py` family, deepened — not the §9 envelope.** Three observations from the live runs:

1. **Handler path (103 sites, 22 modules):** a typed `CongressionalAPIError(APIErrorResponse)` is raised by `DefensiveAPIWrapper.safe_api_request` and rendered by `format_error_response` into the legacy **markdown** string. Observed verbatim for a nonexistent bill/member:
   ```
   ❌ **Error**: Not found: /bill/119/hr/9999999. The resource does not exist at Congress.gov.

   **Error Type**: Not_Found
   **Error Code**: DATA_NOT_FOUND

   **Suggestions**:
   1. Check the identifiers (congress, type, number / bioguide id) for typos
   2. Confirm the item exists with a list/search operation first
   3. This is not a server outage; retrying will not help

   **Additional Details**:
   - **Endpoint**: /bill/119/hr/9999999

   💡 If you continue to experience issues, try simplifying your query or checking the parameter formats.
   ```
   Codes invested in: `DATA_NOT_FOUND` (404), `INVALID_PARAMETERS` (400), `RATE_LIMIT_EXCEEDED` (429, new), `SERVER_ERROR` (5xx), `GENERAL_API_FAILURE` (network) — the `error_type`/`error_code`/`suggestions`/`details` fields of `APIErrorResponse`.
2. **Router path (8 buckets, handlers with no try/except, e.g. `laws`):** the typed error is converted to **`ToolError("<CODE>: <message>")`** — observed: `DATA_NOT_FOUND: Not found: /law/119/pub/999999. The resource does not exist at Congress.gov.` A *second* shape, string-encoded, on the same PR.
3. **Tests that entrench it:** `tests/test_typed_api_errors.py` (250 lines) pins wrapper classification, three representative handlers, **and a static guard that every formatted-error `except Exception` is preceded by the typed clause**; `tests/test_review_p1_fixes.py` adds a static guard that no feature module returns an unwrapped `CommonErrors.*` object. These are exactly the characterization tests the PR-A constraint warned about — they pin the legacy shape, at the static-analysis level, across all 103 sites.

For the §9 contrast (`fulltext/04-tools-responses.md`): `{"error": {"code": "bill_not_found", "message": …, "detail": {…}, "remediation": …}}` — a JSON object with a stable snake_case code, not a markdown blob with `Error Type`/`Error Code` lines, and not a `CODE: message` string. #53 therefore **deepened the legacy shape**: the convergence ruling stands and its cost went up by one more shape (the router `ToolError` string), 103 typed-except sites, and two static tests that will fail the moment the envelope changes. Reporting, not ruling.
